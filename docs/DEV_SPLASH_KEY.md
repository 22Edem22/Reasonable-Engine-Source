# Ключ разработчика заставки (только для владельца движка)

Заставка Reasonable Engine неубиваемая: конечный пользователь не может отключить
или пропустить её никаким способом — ни переменной окружения, ни кликом, ни
настройкой. Это осознанное требование: заставка — часть движка.

## Единственный обход — персональный ключ

Владелец движка (вы) может пропустить заставку персональным ключом:

```bat
setx RE_SPLASH_DEV_TOKEN cd800e3e93931562b9f52aa8d562929f
```

(выполнить один раз, затем перезапустить терминал/редактор). После этого на
вашей машине заставка при запуске проектов не будет отнимать время.

## Как это работает

- В `reasonable/runtime/splash.py` зашит SHA-256 хеш ключа
  (`DEV_TOKEN_HASH`). Ключ нигде не хранится в открытом виде.
- При запуске проекта `developer_splash_bypass()` сравнивает SHA-256
  переменной окружения `RE_SPLASH_DEV_TOKEN` с зашитым хешем. Совпало —
  заставка мгновенно завершается.
- Пользователи ключа не знают: даже зная механизм, подобрать ключ нельзя.
- Для тестов без экрана обход не нужен: в headless-режиме
  (`SDL_VIDEODRIVER=dummy`) заставка завершается мгновенно сама.

## Смена ключа

1. Сгенерируйте новый: `python tools/dev_splash_key.py --gen`
2. Впишите новый хеш в `reasonable/runtime/splash.py` → `DEV_TOKEN_HASH`.
3. Выполните `setx RE_SPLASH_DEV_TOKEN <новый ключ>` и пересоберите
   установщик (`python tools/build_installer.py`).

## Инструменты

```bat
python tools/dev_splash_key.py --gen          :: новый ключ + хеш
python tools/dev_splash_key.py --hash КЛЮЧ    :: хеш ключа
python tools/dev_splash_key.py --check КЛЮЧ   :: подходит ли ключ
```
