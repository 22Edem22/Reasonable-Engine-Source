# ИИ-провайдеры, бесплатные ключи и локальные модели

Reasonable Engine общается с языковыми моделями через **OpenAI-совместимый** `/chat/completions` или нативный **Anthropic Messages API**. Для генерации изображений используется отдельный набор провайдеров.

Настройки открываются в редакторе: **Файл → Настройки ИИ…** (или `Ctrl+,`), раздел **«Провайдеры ИИ»**.

---

## Как выбрать провайдера

1. Откройте **Настройки → Провайдеры ИИ**.
2. Выберите сервис в левом списке.
3. Проверьте **Base URL** и **Модель**. Обычно они уже заполнены.
4. Вставьте ключ, если он нужен.
5. Нажмите **«Загрузить модели»** — редактор запросит список у провайдера.
6. Нажмите **«Проверить подключение»**.
7. Сохраните настройки.

Активный провайдер используется встроенным агентом и ИИ-чатом внутри приложений.

---

## Бесплатно без ключа

Без ключа работают только локальные модели. Встроенных анонимных шлюзов в
Reasonable Engine нет: все облачные провайдеры требуют ваш собственный ключ.

### Ollama (локально)

1. Установите Ollama: <https://ollama.com/download>.
2. Скачайте модель:
   ```bat
   ollama pull qwen2.5-coder:7b
   ```
3. Убедитесь, что сервер запущен:
   ```bat
   ollama serve
   ```
4. В настройках выберите **Ollama (локально)**:
   - Base URL: `http://127.0.0.1:11434/v1`
   - Модель: `qwen2.5-coder:7b` или другая загруженная.

Ключ не нужен, интернет не обязателен. Для агентной работы выбирайте модель от 7B с поддержкой tool calling; на слабом ПК используйте меньшие модели и больше шагов.

### LM Studio (локально)

1. Установите LM Studio: <https://lmstudio.ai>.
2. Загрузите модель.
3. Откройте вкладку **Developer → Local Server** и нажмите **Start**.
4. В настройках Reasonable Engine:
   - Base URL: `http://127.0.0.1:1234/v1`
   - Модель: `local-model` или идентификатор загруженной модели.
5. Нажмите **«Загрузить модели»**, чтобы подставить точный идентификатор.

## Бесплатный ключ

Это не «безлимит»: у каждого сервиса свои лимиты, которые меняются. Ссылки ведут на страницы создания ключей.

| Сервис | Ключ | Модели | Комментарий |
|---|---|---|---|
| **OpenRouter** | <https://openrouter.ai/keys> | Llama, Qwen, DeepSeek, Mistral и другие | Ищите модели с суффиксом `:free`. Один ключ на десятки моделей. Лучший старт для агента. |
| **Google AI Studio** | <https://aistudio.google.com/app/apikey> | Gemini 2.5 Flash / Pro | Бесплатный тариф с лимитами по запросам в минуту и день. |
| **Groq Cloud** | <https://console.groq.com/keys> | Llama 3.3 70B, Qwen 3 | Очень высокая скорость, удобная консоль лимитов. |
| **Cerebras** | <https://cloud.cerebras.ai/> | Llama, Qwen | Бесплатный уровень для разработчиков, быстрые токены. |
| **GitHub Models** | <https://github.com/settings/tokens> | GPT-4o mini, Llama, Mistral | Нужен fine-grained token с доступом к GitHub Models. |
| **Mistral** | <https://console.mistral.ai/api-keys> | Mistral Small, Codestral | Experimental tier; может потребоваться верификация телефона. |
| **Hugging Face** | <https://huggingface.co/settings/tokens> | Огромный каталог open-source моделей | Небольшой лимит кредитов; часть моделей платная. |
| **Cloudflare Workers AI** | <https://dash.cloudflare.com/profile/api-tokens> | Llama, Qwen, Mistral | Ежедневная бесплатная квота. В редакторе выбирается как «Свой сервер» с Base URL Cloudflare. |

### OpenRouter: практический совет

- В каталоге включите фильтр **Free**.
- Скопируйте идентификатор модели, например `meta-llama/llama-3.3-70b-instruct:free`.
- Вставьте его в поле **Модель**.
- Бесплатные модели могут быть перегружены; если пришёл `429`, подождите или выберите другую.

### GitHub Models

Создайте **fine-grained personal access token** и разрешите доступ к GitHub Models. Обычный классический токен тоже может работать, но права стоит ограничить.

## Платные, но стабильные

| Сервис | Ключ | Особенности |
|---|---|---|
| **OpenAI API** | <https://platform.openai.com/api-keys> | Стабильный tool calling, предсказуемое качество кода |
| **Anthropic Claude API** | <https://console.anthropic.com/settings/keys> | Нативный API, отличная автономная разработка |

В Reasonable Engine Anthropic использует нативный формат сообщений и инструментов, а не OpenAI-прокси.

---

## Свой OpenAI-совместимый сервер

Подходит vLLM, llama.cpp server, LiteLLM, OpenWebUI, корпоративный шлюз и другие.

1. Выберите **«Свой OpenAI-совместимый сервер»**.
2. Укажите Base URL, например:
   - `http://127.0.0.1:8000/v1` (vLLM);
   - `http://127.0.0.1:8080/v1` (llama.cpp);
   - `http://127.0.0.1:4000/v1` (LiteLLM).
3. Укажите модель и ключ, если сервер его требует.
4. Нажмите **«Проверить подключение»**.

Сервер должен поддерживать `POST {base_url}/chat/completions`. Для агента желательна поддержка `tools`/`tool_calls`.

## Генерация изображений

Раздел **Настройки → Картинки и спрайты**.

| Провайдер | Ключ | Что делает |
|---|---|---|
| **Процедурные спрайты** | не нужен | Офлайн-генератор: быстро, стабильно, стилизованно |
| **OpenAI-совместимые изображения** | зависит от сервера | `POST /images/generations`, подходит OpenAI, ComfyUI-прокси, SD WebUI-прокси |

Если удалённый провайдер недоступен, включённый **fallback** автоматически создаст процедурный спрайт. Это удобно для офлайн-работы и первых прототипов.

Процедурный генератор понимает цвет и тип объекта: «золотая звезда», «синий кристалл», «зелёный слизень», «ночной лес». Результат детерминирован по промпту и seed.

## Частые ошибки

| Симптом | Что проверить |
|---|---|
| `401 Unauthorized` | Ключ вставлен полностью, без пробелов; выбран правильный провайдер |
| `403 Forbidden` | Права ключа, регион, подтверждение аккаунта |
| `404 Not Found` | Base URL и модель; для OpenAI-совместимых часто нужен суффикс `/v1` |
| `429 Too Many Requests` | Лимит free tier; подождите, смените модель или провайдера |
| Модель отвечает, но агент не вызывает инструменты | Выберите модель с tool calling (Claude, GPT-4.1, Gemini 2.5, Qwen, Llama 3.3) |
| Список моделей не загружается | Некоторые серверы не поддерживают `/models`; введите имя вручную |
| Ollama не подключается | `ollama serve` запущен, модель скачана, порт 11434 свободен |
| Долгий ответ | Локальная модель или перегруженный free tier; уменьшите контекст/шаги |

## Где хранятся ключи

`%APPDATA%\ReasonableEngine\settings.json` — локально на компьютере. В проект и в `project.json` ключи не попадают.

Не передавайте файл настроек другим людям и не коммитьте его в репозиторий. В проекте есть только `ai_config.example.json` — пример конфигурации для ИИ-чата внутри приложения, без реального ключа.
