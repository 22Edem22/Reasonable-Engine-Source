# Русские версии шаблонов Issues (справочно)

GitHub читает шаблоны только из `.github/ISSUE_TEMPLATE`, поэтому рабочие
шаблоны — английские. Здесь лежат их русские переводные копии для удобства:

- [bug_report.yml](bug_report.yml) — «Ошибка»
- [feature_request.yml](feature_request.yml) — «Предложение»
- [config.yml](config.yml) — настройка шаблонов (ссылка на Discussions)

Заполнять issue можно на любом языке — главное, по шаблону.
Английские рабочие шаблоны: [.github/ISSUE_TEMPLATE](../../../.github/ISSUE_TEMPLATE).
