# Reasonable Engine

> **Разумный движок для смелых идей.**
> 2D-игры и приложения на Python с ИИ-агентом, спрайтами, живым прогрессом и экспортом на Windows и Android.

**Версия:** 1.0.0 · релиз **RE-1.01** · **Редактор:** Windows · **Runtime:** pygame · **UI редактора:** PySide6

Reasonable Engine — это не просто библиотека. Это рабочий стол, на котором можно придумать игру или приложение, описать идею обычными словами, собрать проект с ИИ-агентом или вручную, сгенерировать ассеты и получить готовый Windows-пакет или Android-проект для сборки.

## Что умеет

- **Редактор на русском** с тёмной темой, обзором проекта, кодом, ассетами и настройками.
- **Три стартовых сценария вместо анкеты:** создать игру или приложение с ИИ, открыть существующий проект или начать с пустого проекта вручную.
- **Встроенный ИИ-агент:** читает и меняет файлы, запускает проверку, генерирует спрайты и фоны, обновляет план и прогресс.
- **Прозрачный агент:** до запуска показывает план, после запуска — какие файлы изменены, что получилось, что сломалось и как это отменить.
- **История версий и откат:** снимок рабочей версии создаётся автоматически перед каждым запуском агента; любую версию можно вернуть, а само восстановление тоже отменяется.
- **Простые и расширенные настройки:** папка проектов и базовые параметры видны сразу; провайдеры, модели, Base URL, Android и внешние агенты спрятаны под переключателем.
- **Внешний ИИ-агент:** Claude Code, Codex, Cursor, Cline, Windsurf, Aider и другие. Редактор создаёт полный пакет инструкций и показывает прогресс в реальном времени.
- **Один раздел «ИИ-агент»** для проекта: встроенный чат или панель внешнего агента — в зависимости от режима.
- **Ручной режим:** редактор кода с подсветкой, дерево файлов, создание файлов и папок, предпросмотр изображений.
- **Генерация ассетов:** процедурные спрайты офлайн, OpenAI-совместимые серверы изображений.
- **Два типа проектов:** игра и приложение. Один runtime на pygame — общий для Windows и Android.
- **Экспорт Windows:** самодостаточная папка с `Play.bat`; опционально `.exe` через PyInstaller.
- **Экспорт Android:** готовый buildozer/python-for-android проект, ZIP, инструкция и GitHub Actions workflow.
- **Конвертация проекта:** Windows ↔ Android и другие варианты (ориентация, уровни интерфейса, режим агента, чистый прогресс) создают **новый проект**, не меняя исходный.
- **Установщик Windows:** `build_installer.bat` → `ReasonableEngine-Setup.exe` с лицензией, портативным Python и автономным `ReasonablePlayer.exe`. Работает на чистой системе.
- **Сборка редактора в Windows `.exe`:** `build_exe.bat` и `tools/build_editor_exe.py`.
- **Живой прогресс:** `progress/state.json` и `progress/events.jsonl` — общий протокол для встроенного и внешнего агентов.
- **Заставка Reasonable Engine** перед каждым запуском игры или приложения.

## Быстрый старт

### Требования

- Windows 10/11 (редактор).
- Python **3.10+** (проверено на 3.13).
- Для Android-сборки дополнительно нужен Linux или WSL2 — см. [docs/ANDROID.md](docs/ANDROID.md).

### Установка

Откройте PowerShell или командную строку в папке проекта:

```bat
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

`requirements.txt` устанавливает `pygame`, `PySide6` и `Pillow`.

### Запуск редактора

Любой удобный способ:

```bat
python run_editor.py
```

Или двойной клик по `Reasonable Engine.bat` (с консолью) либо `Reasonable Engine (без консоли).vbs`.

Готовый редактор можно собрать в один Windows `.exe`:

```bat
build_exe.bat
```

Сборка использует PyInstaller, вкладывает runtime, шаблоны, документацию и исходники движка для `_engine/`, затем запускает frozen self-test. Результат — `dist/ReasonableEngine.exe`. Подробности: `python tools/build_editor_exe.py --help`.

### Установщик Windows (чистая система)

Для установки на компьютер без Python, PySide6 и pygame соберите полный
установщик:

```bat
build_installer.bat
```

Скрипт по шагам:

1. компилирует защищённую bytecode-копию движка (`engine_source_pyc`);
2. собирает `ReasonablePlayer.exe` — автономный проигрыватель проектов;
3. собирает портативный Python с `pygame` и `Pillow`;
4. собирает `ReasonableEngine.exe` и прогоняет self-test;
5. упаковывает всё в `dist\ReasonableEngine-Setup-RE-1.01.exe` (имя берётся из `VERSION_LABEL` в `reasonable/version.py`).

Для последнего шага нужен [Inno Setup 6](https://jrsoftware.org/isdl.php):

```bat
winget install --id JRSoftware.InnoSetup -e
```

Установщик ставится для текущего пользователя в
`%LOCALAPPDATA%\Programs\Reasonable Engine`, показывает лицензионное соглашение
(`installer\EULA.txt`) и не требует прав администратора. Вместе с редактором
устанавливаются `ReasonablePlayer.exe`, портативный Python и
`THIRD_PARTY_NOTICES.txt`.

Проекты по умолчанию создаются в `<папка установки>\Projects`. Папку можно
изменить в **Настройки → Папка проектов**; выбранный путь сохраняется.

Исходный код ядра в установленной версии не публикуется: проекты получают
скомпилированную копию движка (`_engine/reasonable/*.pyc`). Плоский исходник
остаётся только внутри сборки для Android-экспорта.

Проверка версии:

```bat
python -m reasonable --version
```

## Первый проект

На главном экране три равноправных действия — без обязательного выбора провайдера и модели:

1. **«Создать с ИИ»** — короткий мастер: главная цель одним предложением, игра или приложение, встроенный агент или внешний. На втором шаге — название и папка. Окно, заметки и первая задача настраиваются после создания.
2. **«Открыть проект»** — выбрать существующую папку с `project.json`.
3. **«Пустой проект»** — сразу к результату: без идеи, типа и вопросов про ИИ. Создаётся минимальный `main.py` с пустым окном, `project.json`, папка `assets` и инструкции для агента. Редактор сразу открывает раздел **«Код»**.

Мастер с ИИ создаёт:

- `main.py` с рабочим стартовым шаблоном;
- `project.json` с целью, заметками, платформой и настройками окна;
- ассеты: иконку, фон, стартовых персонажей;
- встроенную копию движка `_engine/reasonable/`;
- `progress/` с планом и live-событиями;
- `AGENT_GUIDE.md`, `skills/`, `re.bat`, `run.bat` и файлы для внешних агентов.

После создания сразу откроется раздел **«ИИ-агент»** (или **«Код»** для пустого проекта). Разделы рабочей страницы: **Обзор**, **ИИ-агент**, **Код**, **Ассеты**. Переключение — кликом или `Ctrl+1…Ctrl+4`.

Кнопка **«Запустить»** в верхней панели запускает проект с заставкой. Результат появляется прямо в обзоре: успешно или с ошибкой, текст ошибки, кнопки **«Запустить снова»**, **«Исправить с ИИ»** и **«Вернуть рабочую версию»**. Так цикл «запустить → посмотреть → исправить → запустить снова» не требует искать консоль. В установленной версии проект открывает `ReasonablePlayer.exe` — отдельный проигрыватель, а не второй экземпляр редактора. **«Экспорт»** открывает Windows/Android-экспорт, **«Конвертировать…»** создаёт новый проект для другой платформы или настроек.

Удалить проект можно с главного экрана (кнопка **×** на карточке недавнего проекта), из боковой панели проекта или через **Проект → Удалить проект…**. Редактор предложит выбрать: убрать только из списка недавних или удалить папку с диска. Системные папки и корень установки защищены от удаления.

Первая задача агенту пишется **после** создания проекта — когда видно, что получилось. Мастер намеренно не спрашивает техническое задание, стиль, разрешение и полноэкранный режим заранее. Провайдер и модель упоминаются только в карточке ИИ и только тогда, когда встроенному агенту действительно нужен ключ.

## История версий и откат

Перед каждым запуском встроенного агента Reasonable Engine автоматически сохраняет полный снимок рабочей версии в `.reasonable/history/`. Снимок не включает `.reasonable`, `_engine`, `.git`, кэши, сборки и виртуальные окружения.

Где смотреть:

- карточка **«История версий»** в обзоре проекта;
- кнопка **«История версий»** в боковой панели;
- **Проект → История версий…** или `Ctrl+Shift+H`;
- карточка **«Что изменил агент»** в чате — список файлов, результат запуска и кнопка **«Отменить эти изменения»**.

В диалоге истории видно, когда сделан снимок, почему, какие файлы изменились после него и что получилось у агента. Любую версию можно вернуть. Перед восстановлением текущее состояние тоже сохраняется отдельным снимком, поэтому неудачный откат можно отменить. Ручной снимок создаётся кнопкой **«Создать снимок»** или **«Снимок сейчас»** в обзоре.

## Два режима ИИ

### Встроенный агент

Встроенный агент — это полноценный tool-calling цикл внутри редактора. Он умеет:

- читать, создавать и точечно редактировать файлы;
- искать по проекту и запускать команды;
- проверять синтаксис и делать headless-прогон;
- генерировать спрайты и фоны;
- вести план, обновлять процент и завершать работу.

Агент не может нажать **«Завершить»**, пока не изменил хотя бы один файл проекта, не прошёл `validate_project` без ошибок и не запустил `run_project` успешно. Установка библиотеки через `pip`, чтение файлов и пустые отчёты не считаются результатом. Если агент останавливается раньше, чат показывает статус **«НЕ ЗАВЕРШЕНО»** с причиной, а прогресс остаётся на 99 %.

Настройка: **Настройки → Провайдеры ИИ**.

| Провайдер | Ключ | Для чего |
|---|---|---|
| **Ollama** | не нужен | Полностью локально, если запущен `ollama serve` |
| **LM Studio** | не нужен | Локальный OpenAI-совместимый сервер |
| **OpenRouter** | бесплатный ключ | Много моделей, включая `:free` |
| **Groq Cloud** | бесплатный ключ | Очень быстрая генерация |
| **Google AI Studio** | бесплатный ключ | Gemini через OpenAI-совместимый endpoint |
| **Cerebras / Mistral / GitHub Models / Hugging Face** | бесплатный ключ | Альтернативные free tier |
| **OpenAI / Anthropic** | платный ключ | Стабильное качество и tool calling |
| **Свой сервер** | зависит от сервера | vLLM, LiteLLM, llama.cpp, корпоративный шлюз |

Для агентной работы важна поддержка **tool calling**. Если провайдер отклоняет инструменты, агент переключается на текстовый JSON-протокол — это работает, но менее надёжно.

Подробное сравнение, ссылки на бесплатные ключи и настройка локальных моделей: **[docs/AI_PROVIDERS.md](docs/AI_PROVIDERS.md)**.

### Внешний агент

Выберите внешний режим при создании проекта — или откройте существующий проект во внешнем агенте.

Редактор создаёт:

- `AGENT_GUIDE.md` — полная инструкция: архитектура, API движка, правила, чек-листы;
- `EXTERNAL_AGENT.md` — как подключить Claude Code, Codex, Cursor, Cline, Windsurf;
- `AGENTS.md`, `CLAUDE.md`, `.cursor/rules/`, `.github/copilot-instructions.md`;
- `skills/` — навыки по движку, играм, приложениям, спрайтам, прогрессу и Android;
- `AGENT_TASKS.md` — стартовый план;
- `re.bat` / `re.sh` — CLI для прогресса, проверки и экспорта.

Промпт для внешнего агента:

> Прочитай `AGENT_GUIDE.md` и `skills/`. Изучи `project.json` и `progress/state.json`. Продолжай разработку по плану, обновляя прогресс через `re.bat`. Доведи проект до запускаемого состояния и выполни `re.bat validate`.

Раздел **«ИИ-агент»** показывает прогресс, события, изменённые файлы и команды. Он обновляется автоматически, даже если агент работает в другом окне. Внешний и встроенный режимы используют один и тот же раздел — меняется только его содержимое.

Подробный сценарий: **[docs/EXTERNAL_AGENTS.md](docs/EXTERNAL_AGENTS.md)**.

## Ручная работа

Reasonable Engine — обычный редактор, а не только чат.

- **Код:** дерево файлов, поиск, редактор с подсветкой Python/JSON/Markdown, сохранение по `Ctrl+S`, создание файлов и папок, предпросмотр изображений.
- **Ассеты:** список спрайтов, фонов, звуков и иконок. Можно сгенерировать спрайт или фон и посмотреть результат.
- **Настройки проекта:** имя, цель, заметки, ориентация и параметры Android. Окно и его размер агент выбирает сам — в настройках их нет.
- **Запуск:** отдельный процесс, консоль с логами, кнопка остановки.
- **Экспорт:** Windows-папка, Windows `.exe` (если установлен PyInstaller), Android ZIP.
- **Конвертация:** новый проект с другой платформой, ориентацией, уровнями интерфейса или режимом агента; исходная папка не меняется.

Ручные изменения не блокируются агентом. Перед запуском и экспортом редактор сохраняет открытые файлы.

## Структура проекта

Каждый проект самодостаточен: его можно скопировать на другой компьютер и запустить без установленного редактора, если есть Python и зависимости.

```text
Мой проект/
├─ main.py                  точка входа
├─ project.json             манифест: цель, заметки, платформа, окно, Android
├─ assets/
│  ├─ icon.png
│  ├─ background.png
│  ├─ sprites/
│  ├─ backgrounds/
│  └─ audio/
├─ progress/
│  ├─ state.json            текущий прогресс и план
│  └─ events.jsonl          история событий
├─ _engine/reasonable/      встроенная копия движка
├─ skills/                  навыки для ИИ-агента
├─ AGENT_GUIDE.md           полная инструкция агенту
├─ AGENT_TASKS.md
├─ AGENTS.md / CLAUDE.md
├─ CONVERSION.md            история конвертации (если проект создан из другого)
├─ re.bat / re.sh           CLI проекта
├─ run.bat / run.sh         запуск
└─ README.md
```

`_engine/` — защищённая копия рантайма. Встроенный агент не может её менять. После обновления Reasonable Engine обновите копию командой:

```bat
re.bat sync-engine
```

## Запуск и заставка

Перед каждой игрой или приложением проигрывается минималистичная заставка Reasonable Engine (в духе Unity и Godot):

- длительность около **1,8 секунды**: тёмный экран, логотип, короткая подпись;
- играет всегда и целиком; отключить или пропустить её нельзя;
- логотип — штатный бренд-ассет движка, работает офлайн.

Запуск из папки проекта:

```bat
run.bat
```

Или:

```bat
python main.py
```

Управление в шаблонах: мышь/касания, `WASD`/стрелки, `Esc` — пауза, `F11` — полный экран.

## Экспорт

### Windows

В редакторе: **Экспорт → Windows**.

Два режима:

1. **Папка Windows** — копия проекта с `Play.bat`, иконкой и инструкцией. Не требует PyInstaller.
2. **PyInstaller `.exe`** — требует установленного PyInstaller:
   ```bat
   python -m pip install pyinstaller
   ```
   Сборка занимает время; готовый `.exe` появляется в папке экспорта.

Windows-пакет содержит `_engine/`, поэтому запускается без установленного редактора.

### Android

В редакторе: **Экспорт → Android**. Будет создан ZIP:

```text
Мой проект-android.zip
├─ main.py
├─ buildozer.spec
├─ assets/ (иконка, presplash, спрайты)
├─ _engine/reasonable/
├─ README_ANDROID.md
└─ .github/workflows/android.yml
```

**Важно:** buildozer/python-for-android не работает на Windows напрямую. Сборка APK выполняется в **Linux** или **WSL2**:

```powershell
wsl --install
```

Затем в Ubuntu/WSL:

```bash
sudo apt update
sudo apt install -y git zip unzip openjdk-17-jdk python3-pip autoconf libtool \
  pkg-config zlib1g-dev libncurses5-dev libncursesw5-dev libtinfo6 cmake \
  libffi-dev libssl-dev
pip install --user buildozer cython
export PATH="$HOME/.local/bin:$PATH"

cd Мой-проект-android
buildozer -v android debug
```

APK появится в `bin/`. Установка:

```bash
adb install -r bin/*.apk
```

Первая сборка скачивает Android SDK/NDK и занимает 15–40 минут. Альтернатива — загрузить проект в GitHub: workflow `.github/workflows/android.yml` соберёт APK в Actions.

Полная инструкция, подпись release, эмулятор и диагностика: **[docs/ANDROID.md](docs/ANDROID.md)**.

## Конвертация проекта

**Проект → Конвертировать в новый проект…** (или кнопка **«Конвертировать…»** в боковой панели). Конвертация всегда создаёт **новую папку** и никогда не меняет исходный проект.

Главная ось — платформа:

- **Windows → Android** — проект получает `platform: android`, Android-пакет и ориентацию; дальше его можно экспортировать как buildozer-пакет.
- **Android → Windows** — проект снова ориентируется на Windows-папку и `.exe`.

В том же диалоге можно изменить:

- название;
- ориентацию (альбомная/портретная) с автоматической сменой сторон базового разрешения;
- уровни интерфейса (Простой tkinter / Стандартный / Продвинутый) — новый проект получит только соответствующие шаблон, ассеты и навыки;
- режим агента (встроенный/внешний) с пересборкой `AGENT_GUIDE.md`, `skills/` и указателей;
- сбросить план, прогресс и ленту событий для чистовой версии.

Что конвертация **не делает автоматически**:

- не заменяет шаблон игры на приложение и наоборот — это меняет смысл проекта;
- не переписывает игровую логику и не адаптирует компоновку под маленький экран (это задача агента после конвертации);
- не импортирует проекты сторонних движков;
- не собирает APK — для этого всё ещё нужен buildozer на Linux/WSL2.

В новом проекте появляется `CONVERSION.md`, а в `project.json` — `converted_from` и история `conversions`. Исходная папка остаётся нетронутой, включая её прогресс и `_engine/`.

То же из CLI:

```bat
re.bat convert --to android --name "Кот на телефоне" --orientation portrait --reset-progress
```

## CLI

Внутри проекта используйте `re.bat` (Windows) или `re.sh` (Linux/macOS). Из корня движка — `python -m reasonable.cli --project <папка> <команда>`.

```bat
re.bat status
re.bat plan "Собрать меню" "Добавить уровни" "Проверить"
re.bat task t2 in_progress
re.bat progress 45 "Готов экран меню" --stage "Меню"
re.bat event "Добавлены враги"
re.bat validate
re.bat run --headless
re.bat done "Проект готов"
```

Полезные команды:

| Команда | Назначение |
|---|---|
| `status` | проект, статус, процент, план |
| `events` | последние события |
| `plan` | заменить план работ |
| `task` | обновить задачу |
| `progress` | процент, этап, сообщение |
| `event` | записать событие |
| `done` | завершить на 100% |
| `validate` | проверить структуру и синтаксис |
| `run --headless` | запуск без окна на несколько кадров |
| `sprite` / `bg` | сгенерировать ассет |
| `export windows\|android` | экспорт |
| `convert --to windows\|android` | создать новый проект с другой платформой/настройками |
| `sync-engine` | обновить `_engine/` |
| `pack` | обновить пакет инструкций агента |
| `init` | создать проект из CLI |
| `settings` | показать/сменить провайдера |
| `version` | версия движка |

## Настройки и безопасность

- Настройки редактора и API-ключи хранятся локально:
  `%APPDATA%\ReasonableEngine\settings.json`.
- По умолчанию открыты только **основные настройки**: папка проектов, предпросмотр и статус ИИ. Провайдеры, модели, Base URL, картинки, параметры Android и внешних агентов — под переключателем **«Расширенные настройки»**. Выбор запоминается в `ui.advanced_settings`.
- В проект ключи **не записываются**. `ai_config.example.json` — только пример для встроенного ИИ-чата приложения.
- История версий лежит в `.reasonable/history/` внутри проекта. Снимки не включают `.reasonable`, `_engine`, `.git`, кэши, сборки и виртуальные окружения.
- Ключи отображаются в интерфейсе скрыто; кнопка «Показать» — временно.
- Встроенный агент работает в песочнице проекта: нельзя выйти за папку проекта, изменить `_engine/`, удалить `main.py`, `project.json` и файлы прогресса.
- Агент может выполнять команды в папке проекта. Проверяйте незнакомые действия, особенно при работе с внешними моделями.
- Внешний агент — обычный процесс на вашем компьютере. Reasonable Engine создаёт инструкции и читает прогресс, но не ограничивает внешний агент технически. Работайте с проверенными инструментами и храните резервные копии.

## Тесты

Тесты используют стандартный `unittest`, без дополнительных зависимостей:

```bat
python -m unittest discover -s tests -v
```

Editor-тесты запускаются в offscreen-режиме Qt и проверяют двухшаговый мастер, настройки, редактор кода, генерацию спрайта, конвертацию и открытие проекта. Полный прогон также создаёт проекты, запускает оба шаблона headless, конвертирует Windows→Android, экспортирует Windows-папку и Android ZIP.

Frozen self-test редактора:

```bat
dist\ReasonableEngine.exe --self-test
```

Он проверяет ресурсы, offscreen-окно, создание проекта, встроенный движок, настройки окна, конвертацию и валидацию. Отчёт можно направить в файл переменной `REASONABLE_SELF_TEST_REPORT`.

Подробнее: **[docs/TESTING.md](docs/TESTING.md)**.

## Ограничения

- Редактор работает на **Windows**; runtime и CLI кроссплатформенные.
- **APK не собирается на Windows** напрямую. Экспорт создаёт готовый проект и инструкцию; сборка — Linux/WSL или GitHub Actions.
- **Конвертация платформы** меняет метаданные, окно, ориентацию и инструкции, но не переписывает игру автоматически. Проверьте управление и компоновку после конвертации.
- Бесплатные тарифы провайдеров могут менять лимиты, модели и условия. Для стабильной работы используйте свой ключ или локальную модель.
- Качество ИИ-агента зависит от модели и поддержки tool calling. Результат всегда стоит проверять.
- Пока нет 3D, мультиплеера, физического редактора и магазина ассетов. Это осознанный фокус на 2D-играх и приложениях.
- Android-сборка требует установленного Android SDK/NDK; первый билд долгий.
