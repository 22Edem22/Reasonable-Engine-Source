СТОРОННИЕ КОМПОНЕНТЫ REASONABLE ENGINE
Дата обновления: 2026

Reasonable Engine включает перечисленные ниже сторонние компоненты. Каждый
компонент распространяется на условиях собственной лицензии. Тексты лицензий
поставляются вместе с компонентами и доступны по указанным ссылкам.

-------------------------------------------------------------------------------
1. Python
-------------------------------------------------------------------------------
Версия: 3.13 (встроенная среда выполнения и ReasonablePlayer)
Лицензия: Python Software Foundation License 2.0
Сайт: https://www.python.org/
Лицензия: https://docs.python.org/3/license.html
Примечание: включает стандартную библиотеку Python и библиотеку zlib.

-------------------------------------------------------------------------------
2. pygame (pygame-ce)
-------------------------------------------------------------------------------
Назначение: графика, ввод, звук и игровой цикл созданных проектов.
Лицензия: GNU Lesser General Public License 2.1 или новее (LGPL-2.1-or-later)
Сайт: https://www.pygame.org/
Лицензия: https://www.gnu.org/licenses/old-licenses/lgpl-2.1.html
Примечание: pygame используется как динамически подключаемая библиотека.
Исходный код доступен на сайте проекта.

-------------------------------------------------------------------------------
3. PySide6 / Qt for Python
-------------------------------------------------------------------------------
Назначение: интерфейс редактора Reasonable Engine.
Лицензия: GNU Lesser General Public License 3.0 (LGPL-3.0)
Сайт: https://doc.qt.io/qtforpython-6/
Лицензия: https://www.gnu.org/licenses/lgpl-3.0.html
Примечание: Qt и PySide6 используются как разделяемые библиотеки; их исходный
код доступен на сайте Qt. Пользователь вправе заменить библиотеки Qt/PySide6
совместимыми версиями.

-------------------------------------------------------------------------------
4. Pillow (PIL Fork)
-------------------------------------------------------------------------------
Назначение: обработка изображений, генерация спрайтов и иконок.
Лицензия: Historical Permission Notice and Disclaimer (HPND)
Сайт: https://python-pillow.org/
Лицензия: https://github.com/python-pillow/Pillow/blob/main/LICENSE

-------------------------------------------------------------------------------
5. Inter (шрифт)
-------------------------------------------------------------------------------
Назначение: интерфейс редактора.
Лицензия: SIL Open Font License 1.1
Сайт: https://rsms.me/inter/
Лицензия: https://scripts.sil.org/OFL
Файл лицензии: reasonable/assets/fonts/OFL-Inter.txt

-------------------------------------------------------------------------------
6. Unbounded (шрифт)
-------------------------------------------------------------------------------
Назначение: заголовки и фирменный стиль.
Лицензия: SIL Open Font License 1.1
Сайт: https://fonts.google.com/specimen/Unbounded
Лицензия: https://scripts.sil.org/OFL
Файл лицензии: reasonable/assets/fonts/OFL-Unbounded.txt

-------------------------------------------------------------------------------
7. Inno Setup (только установщик)
-------------------------------------------------------------------------------
Назначение: создание установщика Windows Reasonable Engine.
Лицензия: Inno Setup License
Сайт: https://jrsoftware.org/isinfo.php
Примечание: Inno Setup не входит в состав установленной программы; он
используется только на этапе сборки установщика.

-------------------------------------------------------------------------------
8. API-сервисы (по выбору пользователя)
-------------------------------------------------------------------------------
OpenRouter, Groq, Google AI Studio, OpenAI, Ollama, LM Studio и другие сервисы
не входят в состав Программы. Пользователь подключает их самостоятельно и
принимает их условия использования и политику конфиденциальности.

-------------------------------------------------------------------------------
Полные тексты лицензий LGPL и OFL можно получить по ссылкам выше или запросить
у автора Reasonable Engine. Настоящий файл не изменяет условия лицензий
сторонних компонентов.
